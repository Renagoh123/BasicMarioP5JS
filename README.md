# BasicMarioP5JS

A simple Mario-style side-scrolling game built with **p5.js**.  
Help your character collect **red apples** on the way home while avoiding **poisonous purple apples** and falling into **canyons**.  
How high can you score?

## Technologies Used
- **JavaScript**
- **p5.js** (Creative Coding Library)
  
## Controls & Gameplay
### Controls:
- **Move Right**: `D` key or `→` arrow
- **Move Left**: `A` key or `←` arrow
- **Jump**: `Spacebar`

### Gameplay Rules:
- ✅ Collect **red apples** to earn points (+1 per apple)
- ❌ Avoid **purple apples** — they're poisonous!
- ⚠️ Don’t fall into **canyons** — it ends your run!

Try to stay alive and rack up the highest score you can!
